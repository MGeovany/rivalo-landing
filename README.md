# Rivalo Landing

Minimal Astro marketing and policy site for Rivalo.

## Routes

- Production: `https://rivalo.thefndrs.com`
- `/` — marketing page
- `/support` — Apple support URL
- `/privacy` — privacy policy URL
- `/terms` — terms of use

## Local Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
